# Kroki + Niolesk: Diagram-as-code rendering services

Kroki: https://kroki.io/ - Diagram-as-code tools bundled into a common API
Niolesk: https://niolesk.top/ - Web frontend for Kroki, offering an editor w/ preview, and many useful examples

This is a usable example of how to run Kroki and Niolesk together in a self-hosted way.
It makes using DaCwatch run faster, and keeps your data private.

Kroki local endpoint: http://localhost:48000
Niolesk local endpoint: http://localhost:48080
